# data/raw/ — 외부 raw 데이터 archive

ADR-015 데이터 트랙(Sub A~E + 후속) 진행 중 사용한 공공/외부 데이터의 원본을 박제한다.

- 목적: 출처/라이센스 추적, 데이터 갱신 시 ingest 재실행 reference, 사용자 Downloads/ 정리 가이드.
- 원칙: 이 폴더는 **archive 백업** 용도. ingest script 입력은 `tasks/` 또는 fixtures/에 별도 보존(영향 없음).
- 인코딩: CSV는 모두 UTF-8 (cp949 원본은 변환 후 박제). xls/xlsx는 그대로.

## 디렉터리 구조

| 폴더 | 용도 |
|---|---|
| `used/` | ADR-015 ingest로 활용된 원본 (PR 머지됨) |
| `external-lines/` | LineNumber 확장 보류 노선 (PR #1474, 사용자 결정 2026-06-18) |
| `api-meta/` | OpenAPI 응답 스키마/샘플 메타 xls (참조용) |

## api-meta/ — OpenAPI 메타 (참조용)

공공데이터포털에서 받은 OpenAPI 응답 스키마/샘플 xls. ingest 직접 입력 X, 스키마 reference로만 사용.

| 파일 | API | 활용 |
|---|---|---|
| `서울시+교통공사+지하철역+열차시간표+현황.xls` | `getTrainSch` | Sub C Tier 1 (열차 시간표) |
| `서울교통공사_역코드로+지하철+열차+시간표+검색.xls` | `SearchSTNTimeTableByID` | Sub C Tier 2 (역 기준 시간표) |
| `서울교통공사_지하철+호선별+첫차와+막차+정보(전철역코드,외부코드).xls` | 첫차/막차 | PR #1490 |

참고 (Downloads에 없으나 Sub A에서 사용 중인 API):
- `서울교통공사_최단경로` / `서울시 교통공사 지하철역 최단경로이동정보` — Sub A 참조
- 서울시 지하철 실시간 도착정보 — 이미 핵심 사용 중
