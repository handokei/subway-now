## 배경

현재 우리 앱은 **서울 Open Data 실시간 도착정보** 1개 API에만 의존하고 있다. 공공데이터포털(data.go.kr) + 레일포털(KRIC)에는 우리 앱이 안 쓰는 지하철 관련 API가 다수 존재하고, 그 중 일부는 사용자 가치에 직접 기여 가능하다. 본 문서는 **카탈로그 + 우선순위 + sub-epic 추천**을 정리한다.

조사 방식: WebFetch + WebSearch만 사용. 키 발급/실제 호출은 안 함. 응답 필드/갱신주기는 공공데이터포털 공식 페이지 기준.

### F. 레일포털 KRIC (data.kric.go.kr) — 60개 API, 전국 도시철도 통합

- 인증: serviceKey 필수, **일일 사용한도 무제한 / 무료**
- 운영기관 코드(railOprIsttCd)로 서울교통공사(S1) / 코레일(KR) / 기타 분기
- 주요 endpoint:
  - **시간표** (일반 + 급행) — 첫차/막차 포함
  - **역사 혼잡도** (stationCongestion) — KRIC 자체 측정
  - 환승 동선 (transfer movement route)
  - 승강장 정보
  - 출입구→승강장 경로
  - 차량/역사 시설 정보
  - 열차 환경 데이터(CO2/NO2/PM2.5)
- 추정 활용: **공항철도/신분당선/우이신설/GTX/인천1·2호선/부산** 등 코레일 외 비-서울 노선 데이터를 KRIC 단일 키로 커버 가능 (운영기관 코드 정확한 매핑은 확인 필요)

### 미확인 / 검색되지 않음
- **신분당선·공항철도·GTX 단독 API** — data.go.kr에서 직접 검색 안 됨. KRIC 통합으로 커버 추정 (확인 필요)
- **칸별 실시간 혼잡도** — data.go.kr 공식은 분기 단위 통계 csv(15071311)만. 실시간은 **SK openapi 유료** (geovision puzzle). KRIC stationCongestion이 실시간인지 확인 필요
- **인천교통공사 1·2호선 단독 API** — 검색에 직접 hit 없음 (확인 필요)

## 우선순위

### P0 (코드 인프라 일부 있음 + 사용자 가치 큼)

1. **15143840 빠른하차정보** → 칸별 추천 / 환승 시 최적 탑승칸 안내. 현재 우리 앱은 `exitSide`만 있고 칸/문 번호는 없음. ADR 후보.
2. **15143847 열차시간표 (막차/첫차)** → **#1043과 직접 통합**. 현재 자체 막차 추정 없음. 새벽 운행 안내까지 확장 가능.
3. **15144070 지하철알림정보** → 운행 차질 시 알람 우선순위 다운 / 사용자에게 배너. 현재 우리 알람은 정상 운행 가정. 1분 갱신 → BG 폴링 부담 적음.

### P1 (가치 있음 + 새 인프라 필요)

4. **15057802 역간거리/소요시간** → 현재 `stationEta` 보완. ETA 정확도 직결 (실측 vs 공식 timetable diff 비교).
5. **15098554 TAGO 출구별 정보 + 출구별 버스노선** → 길찾기 결과에 "하차 후 ○번 출구 → ○○버스 환승" 표시.
6. **15143846 실시간운임정보** → 경로 결과에 운임 노출 (기후동행카드 분기 포함).
7. **KRIC stationCongestion** → 혼잡도 기반 칸 추천 / 알람 우선순위 (실시간 여부 확인 후 결정).

### P2 (nice-to-have)

8. **15098158 엘리베이터 위치** + **승강기 가동현황** → a11y 모드.
9. **15057719 역명 검색 / 15058404 노선별 역 정보** → stations.json drift 검증 스크립트.
10. **TAGO 출구별 주변시설** → "지상 위 ATM/편의점" 안내.

### 보류
- 광역철도 (코레일) — 우리 앱 즐겨찾기 사용량 확인 후 결정.
- 부산/대구/광주 등 비-서울 — 시장 확장 시.
- 칸별 실시간 혼잡도(SK 유료) — 비용 ROI 검토 별도.
