## 조사 결과

### 1순위 후보 — 서울교통공사 지하철 알림정보 API

- 출처: data.go.kr (공공데이터포털) ID `15144070`
  - https://www.data.go.kr/data/15144070/openapi.do
- 제공자: 서울교통공사
- 형식: REST, JSON + XML
- 갱신 주기: **1분**
- 비용: 무료
- 인증: 공공데이터포털 인증키 (개발 10,000 req/day, 운영은 확장 신청)
- 응답 필드: `알림 제목`, `알림 내용`, `알림구분코드`, `이례 상황 시작 일시`, `종료 일시`
- 커버 케이스 (운영사 공시):
  - 열차 지연
  - 각종 사고
  - 역 주변 시위 등 혼잡으로 인한 무정차 안내
  - 시간표 변경
  - 기타 이례 상황 공지

**한계 / 확인 필요:**
- 정확한 endpoint URL/파라미터 스펙은 data.go.kr 상세 페이지 접근 시 API 키 발급/로그인 필요 → **별도 작업으로 키 발급 후 확정** 필요
- 노선/역 단위 필터 가능 여부 미확인 (전역 알림만 내려올 가능성)
- 알림구분코드 enum 미확인 → 처음 통합 시 raw 텍스트 표시 + 점진 분류
- 서울교통공사 운영 노선(1·2·3·4·5·6·7·8·9) 외(코레일/공항철도/신분당선/우이신설/김포/GTX)는 **커버 안 됨**

### 2순위 보조 데이터 (커버 보완)

- **레일포털 (KRIC)** https://data.kric.go.kr/ — 코레일/광역철도 운행정보, 별도 조사 필요
- TOPIS https://topis.seoul.go.kr/ — 서울 교통정보 종합. 돌발/사고 데이터 있으나 도로 중심
- 비공식: 서울교통공사 공식 X(트위터), 지하철 공식 안내 채널 — 비공식 스크래핑 사양 위험

### 3순위 (비추천)

- 카카오/네이버 지하철 — public API 없음, 비공식 스크래핑 ToS 위반 위험

## 추천 접근

서울교통공사 `지하철 알림정보 API`를 backend(alarm-worker)에서 1분 주기 cron으로 폴링 → KV cache → 클라이언트가 home/arrival 화면에서 노선별 active alert 표시. 서울교통공사 미커버 노선은 향후 KRIC 별도 epic.
