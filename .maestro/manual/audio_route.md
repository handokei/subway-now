# Manual — 이어폰/오디오 라우트 감지

audio session 변경은 시뮬레이터에서 재현 불가. 실기기 + 실제 오디오 디바이스 필요.

## 사전 준비
- 실기기 + 유선 이어폰 또는 블루투스 헤드셋.
- modules/audio-route 모듈이 포함된 빌드.

## 시나리오
1. 앱 실행 → 알람 발화 직전 상태 구성.
2. 이어폰 연결 → 알람 발화 시 사운드가 이어폰으로 출력.
3. 이어폰 분리 → 외부 스피커로 자동 라우트.
4. 블루투스 헤드셋 연결/해제 동일 검증.

## 합격 기준
- 오디오가 현재 활성 라우트로 일관 출력.
- 알람 끄기 후 audio session이 정상 해제.
