# Manual — BG 도착 알람

시뮬레이터/Maestro로 검증 불가. 실기기에서 매 릴리스 직전 확인.

## 사전 준비
- 위치 권한 "항상" 허용 + 알림 권한 허용.
- 실기기에서 production 또는 development 빌드 설치.

## 시나리오
1. 강남역 부근에서 앱 실행 → 목적지 "잠실" 설정 → 취침 모드 ON.
2. 앱을 백그라운드로 전환 (홈 버튼).
3. 실제 지하철 탑승 또는 이동(잠실새내 부근 도달).
4. 디바이스가 잠겨 있어도 잠실 도착 알림이 사운드와 함께 표시되는지 확인.

## 합격 기준
- BG 진입 후에도 알람이 사용자가 잠실 1정거장 전 도달 시점에 발화.
- 알림 사운드가 재생되고 Live Activity가 잠금화면에 표시.
- 알람 끄기 동작 후 앱이 정상 상태로 복귀.
