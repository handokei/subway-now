## 2. 🔴 신규 최우선 결함 (미수정) — backstop이 새 트립을 죽인다

`src/shared/hooks/useStateRehydration.ts:273`:
```ts
async function runNavigationPauseBackstop(trigger: 'mount' | 'active') {
  const pausedAt = await getNavigationPausedAt();   // AsyncStorage — 앱 재시작에도 생존
  if (!isPauseAutoEndDue(pausedAt, now)) return;    // pausedAt + 15분 경과면 통과
  await runTripBoundCleanups();                      // → DELETE /trips (#2129)
  useDestinationStore.setState({ destination: null, ... });
}
```

**`pausedAt`만 보고 trip 신원을 확인하지 않는다.** 함수 doc이 그 전제를 명시 —
> *"pausedAt은 trip 종료 전체 경로(TRIP_BOUND_CLEANUPS)에서 항상 함께 제거되므로, 이 값이 남아있다는 것 자체가 '아직 어떤 종료 경로도 거치지 않은 활성 일시정지'를 의미한다 — **destination 존재 여부를 별도로 재확인할 필요 없음**"*

→ `pausedAt`을 지우지 않는 종료 경로가 **하나라도** 있으면 이 불변식이 깨지고 **오래된 `pausedAt`이 새 트립을 종료**시킨다. `trigger`가 `'mount' | 'active'`라 **앱 실행·FG 복귀마다 재발**한다.

### 실측 (D1 `trip_events`, 2026-10-15 11:55Z — 배포 직후)
```
11:55:34  트립 생성
11:55:39  la-token-register → trip_not_found
11:55:40  trip-end {reason:"user-delete", endPath:"http-delete"}   ← backstop 발화
11:55:42  la-token-register → trip_not_found
11:55:47  la-token-register → trip_not_found
11:55:49  사용자가 안내 시작 재탭 → 재등록
이후      la-token-register 재시도 없음 → activityState: none, activityPushToken: none
```

사용자 증언: *"내가 삭제한 게 아니라 **안내 시작했는데 그게 자동으로 다시 꺼져서** 내가 다시 안내시작을 누른 거야."*
**`reason: "user-delete"`는 라벨이 거짓말을 한 것이다** — device가 보낸 DELETE를 backend가 그렇게 라벨링한 것이고 실제 주체는 backstop이다. 주체를 함의하는 라벨을 증거로 쓰지 말 것.

### 파생 결함 — LA 등록이 포기한다
`trip_not_found` **3회 후 재시도하지 않는다** → 트립이 되살아나도 **LA 토큰이 영구 부재**.

### 왜 이게 최우선인가
**LA 토큰이 없으면 backend가 LA push를 보낼 대상이 없다.** #3000이 `boardingPhase`를 content에 넣어도 전달 경로가 없으므로 **버튼이 보이지 않는다.** 실측으로 확인된 *"탑승하셨냐는 알림(프롬프트)은 왔는데 LA는 없다"*가 정확히 이 결과다 — 프롬프트는 **원격 alert push**라 LA 토큰이 불필요하기 때문.

→ **이것을 고치지 않으면 #3000·#3001·향후 S4가 전부 무의미하다.**

## 7. 조사 함정 (반복 방지)

- **`trip_metrics`에 트립이 없다 ≠ 트립이 없다.** 그 테이블은 **종료 시** 적재 — 진행 중 트립은 원리적으로 안 보인다. 진행 중 판정은 KV: `npx wrangler kv key get "trip:<deviceTokenHash>" --binding TRIPS --remote --config wrangler.toml`.
- **시각 상수를 손으로 적지 말 것.** `Date.parse(ISO)`로 계산하고 `SELECT datetime(상수/1000,'unixepoch')`로 역검증한다. 28시간 틀린 상수(미래 시각)를 써서 `ts > DEPLOY` 필터가 **실재 이벤트를 0건으로 숨겼다** — 더 나쁜 건 그 0이 "정상 PASS" 방향이었다.
- **`COUNT(*)`가 0행을 반환하면 쿼리 실패다**(항상 1행). `GROUP BY`는 0행이 정상 — 구분할 것.
- **주체를 함의하는 라벨(`user-*`)을 증거로 쓰지 말 것.** `endPath`처럼 **경로**를 함께 봐야 구분된다.
